## 三、四个设计决定

1. **id 404 是一次运行时探测，且可注入。** 日志只知道「当初画的是什么」，不知道「那些字节还在不在」。所以在挂载地图**之前**对每个图层的 URL 发一次 `HEAD`：`404/410` ⇒ 「数据已不可用（并点名图层）」；**探测本身抛错不算数据没了**（网络/实现故障不是证据），照常挂载，让地图报自己的错。
2. **三种降级是同一张卡的三种状态，不是三个组件。** 一个 `data-gis-render-card` 属性就能被断言：`failed` / `orphan` / `data-unavailable` / `ready`。
3. **可用性只「细化」ready 卡。** 失败或不配对的卡保留自己的状态——最初写成「只要探测有结论就覆盖状态」，于是失败卡显示成 `data-unavailable`，**被本轮的 DOM 测试当场抓住**（见第五节）。
4. **单独的 web 车道，而不是把 DOM 塞进节点车道。** 节点车道 145 条测试保持无 DOM；web 车道 7 条只跑 `*.web.spec.tsx`。

## 四、实测（两条车道 + 产物）

- **DOM 车道 7 条（`pnpm test:web`，jsdom + 真组件）**：
  - 失败结果 → 渲染出诊断（含错误码与首行原因），属性为 `failed`；
  - `call === null` → 渲染出 `callId`，属性为 `orphan`；
  - **字节已消失** → 渲染出「no longer available (ds_1)」，属性为 `data-unavailable`，且**根本没有创建地图**（`constructed` 为空）——降级不是「一张空补丁的地图」；
  - 数据在 → 真挂载地图并画出图层；**探测抛错**时照常挂载；
  - **回放一致（DOM 级）**：同一条块与其 JSON 往返副本渲染出的 `innerHTML` **完全相同**（成功与失败各一条）；
  - **都不抛异常**：8 种畸形块（空对象、无 meta、meta 不是对象、layers 不是列表、图层缺字段、isError、argsRaw 不是 JSON…）逐个 `render()` 不抛。
- **节点车道 145 通过 + 1 跳过**（未受影响：web 车道用不同的文件名模式隔离）。
- **产物契约 23 条**：入口 → 卡片 chunk → MapLibre chunk，无同步 chunk require、无孤儿。

## 五、本轮抓到的两件事

1. **我自己的 bug，被 DOM 测试抓住**：可用性探测的结果无条件覆盖了卡片的 `data-gis-render-card`，于是**失败卡显示成「数据已不可用」**——诊断被吞掉。这正是本项目最在意的那类静默错误，只不过这次它发生在 5 分钟前刚写的代码里。修法：可用性只细化 `ready` 卡。
2. **工具链坑（值得记）**：`@testing-library/react@16` 的 peer 自动装了 **react-dom@19**，而本仓库是 react@18 ⇒ 导入期即 `TypeError: Cannot read properties of undefined (reading 'S')`，报错完全看不出根因。修法：把 `react-dom@^18` 显式钉进根 devDependencies。

## 六、诚实边界

1. **本轮是「组件级 e2e」**：真组件、真 DOM、真状态机，但 MapLibre、可用性探测、传输都是注入的替身。**浏览器 + 真实会话回放**仍未做——它属于 T2.10。
2. **但 T2.10 不再被凭据卡住**（本轮的重要发现）：DSH 自带 `@deepseek-ai/dsh-llm-mock-server`（`pnpm run mock:llm`，行为含 **`tool_call_success`**），把它设成 provider 就能在**没有 API key** 的情况下驱动一次真实的 `gis_render` 工具调用，从而让真卡片在真浏览器里渲染、并回放它。M0 的 T0.3 与 M1b 的「需要凭据」边界至此有了一条可执行出路。
3. **会话日志不是手写的**：真实会话落盘为 `sessions/<workspace-slug>/<id>/session.v4.jsonl.zstd`（zstd 压缩 + 工作区登记），手造它比走 mock provider 贵得多——**建议 T2.10 走 mock provider，不要手写日志**。
4. **可用性探测只装在卡片上**，不在共享地图组件里：组件只画别人让它画的东西，「回放语义」属于卡片。
5. **部分可用没有做**：只要有图层 404，整张卡降级；「画出还在的、同时说明谁没了」未实现。
6. **挂载之后才失效的图层**（探测通过、随后被删）仍属 MapLibre 的静默失败地带：地图会是一片空补丁 + 控制台噪音，本轮未处理。
7. **`HEAD` 探测的成本未测**：每个图层每次挂载一次请求。
